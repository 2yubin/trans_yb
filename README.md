# trans_yb

조테로(Zotero) 10에서 영어 논문 PDF를 맥락에 맞게 한국어로 번역해 오른쪽 사이드바에 보여 주는 플러그인이에요. 번역 문장에 커서를 대면 원문의 같은 문장이 함께 표시돼요.

## 주요 기능

- **맥락 번역**: 페이지 전체, 논문 제목, 앞 페이지 마지막 문단을 함께 보내 문단 단위로 자연스럽게 번역해요. 쪽 끝에서 잘린 문장은 다음 쪽 첫 부분까지 합쳐서 번역해요.
- **번역 엔진**: Claude Code, Codex(로그인된 계정 사용, API 키 불필요), Claude API, Google(무료)
- **문단 알아보기**: 글자 위치, 들여쓰기, 줄 간격, 글꼴로 문단·소제목·참고문헌·주석을 나눠요. 머리말, 꼬리말, JSTOR 안내문, 쪽 번호는 번역하지 않아요.
- **원문 대조**: 번역 문장과 원문 문장을 서로 회색으로 표시해요. 스캔 PDF의 OCR 글자 폭도 보정해요.
- **형광펜·밑줄**: 조테로와 같은 8색. 번역문 일부에 칠하면 원문의 같은 부분에도 조테로 주석이 생기고, 원문에서 칠하거나 지우면 번역문도 따라와요.
- **각주**: 각주 번호는 위첨자로 보여 주고, 누르면 각주 내용을 번역해서 보여 줘요. 주석 문단은 따로 표시해요.
- **서지 정보**: 맨 앞에 "Park·Abelmann(2004)의 「제목」" 형식으로 보여 줘요.
- **미리 번역**: 지금 쪽과 다음 두 쪽 자동 번역, 전체 또는 쪽 범위 번역. 번역 결과는 저장해서 다시 쓰고 토큰을 아껴요.
- **스캔한 책**: 옆으로 눕혀 스캔한 쪽(90·180·270도), 한 장에 펼친 두 쪽, 기울어진 스캔도 바로 세워 읽어요.
- **깨진 대문자**: 글꼴 문제로 대문자가 소문자로 들어간 PDF(예: "however", "heath 2003")도 문장을 제대로 나눠요.
- **읽기**: 번역은 오른쪽 칸에 끝까지 쭉 보여요. 번역 끝에서 조금 더 내리면 다음 쪽으로 넘어가고, 새 번역의 맨 위가 보여요. 오른쪽 아래에 "‹ 이전 쪽", "다음 쪽 ›" 단추가 늘 떠 있어요.

## 설치

1. [Releases](https://github.com/2yubin/trans_yb/releases/latest)에서 `trans_yb.xpi`를 받아요.
2. 조테로에서 Tools → Plugins → 톱니바퀴 → Install Plugin From File로 설치해요.
3. 조테로를 껐다 켜요.

설치한 뒤에는 새 버전이 나오면 조테로가 알아서 업데이트해요(Tools → Plugins → 톱니바퀴 → Check for Updates로 바로 확인할 수도 있어요).

조테로 10에서만 설치돼요. 맥에서만 시험했어요. Claude Code나 Codex 엔진을 쓰려면 그 프로그램이 설치되고 로그인돼 있어야 해요.

## 폴더 구조

| 파일 | 하는 일 |
|---|---|
| `addon/manifest.json` | 플러그인 이름, 버전, 지원하는 조테로 버전 |
| `addon/bootstrap.js` | 조테로가 플러그인을 켜고 끌 때 부르는 입구 |
| `addon/prefs.js` | 기본 설정 |
| `addon/content/trans_yb.js` | 실제 기능. 위쪽은 문단·문장 계산, 아래쪽은 조테로 화면 연결 |
| `addon/locale/` | 사이드바 제목 문구 |
| `test/` | 문장 나누기, 문단 알아보기, 각주 찾기 시험 |
| `build.sh` | 시험을 돌리고 `build/trans_yb.xpi`를 만들어요 |

## 고친 뒤 다시 만들기

```sh
sh build.sh     # 시험을 돌리고 설치 파일을 만들어요
sh release.sh   # (저장소 주인) manifest.json 버전을 올린 뒤 실행하면 Releases에 올리고 자동 업데이트 정보를 고쳐요
```

## 개인정보

번역할 때 논문 문장이 고른 번역 엔진(Anthropic, OpenAI, Google)의 서버로 보내져요. 번역 결과와 기록은 조테로 데이터 폴더의 `trans_yb` 안에 저장돼요.
