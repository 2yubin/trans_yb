# trans_yb

조테로(Zotero) 10에서 영어 논문 PDF를 맥락에 맞게 한국어로 번역해 오른쪽 사이드바에 보여 주는 플러그인이에요. 번역 문장에 커서를 대면 원문의 같은 문장이 함께 표시돼요.

## 주요 기능

- **맥락 번역**: 페이지 전체, 논문 제목, 앞 페이지 마지막 문단을 함께 보내 문단 단위로 자연스럽게 번역해요. 쪽 끝에서 잘린 문장은 다음 쪽 첫 부분까지 합쳐서 번역해요.
- **번역 엔진**: Claude Code, Codex(로그인된 계정 사용, API 키 불필요), Claude API, Google(무료)
- **문단 알아보기**: 글자 위치, 들여쓰기, 줄 간격, 글꼴로 문단·소제목·참고문헌·주석을 나눠요. 머리말, 꼬리말, JSTOR 안내문, 쪽 번호는 번역하지 않아요.
- **읽는 순서**: PDF 안에 글자가 어떤 순서로 저장돼 있든, 글자 위치만 보고 위에서 아래로, 왼쪽 단에서 오른쪽 단으로 읽어요. 첫 쪽처럼 제목·초록은 한 단이고 본문은 두 단인 배치도 순서대로 읽어요. 여러 줄로 나뉜 큰 제목은 한 제목으로 합쳐 번역해요.
- **표·그림 해석**: 번역문에서 표·그림 제목(Table 1, Figure 2, <표 1>, 그림 3) 아래의 **표 해석**, **그림 해석** 단추를 누르면 그 쪽을 그림으로 만들어 엔진에 보내요. 한눈에 보기, 읽는 법, 눈에 띄는 결과, 논문에서의 의미, 해석할 때 조심할 점을 풀어 주고, 결과는 저장해 다시 써요(Claude Code, Codex, Claude API에서 돼요. Google은 안 돼요). 표 칸 안의 글자는 번역 목록에 조각으로 섞이지 않게 빼고, 해석 칸에서만 풀어 줘요(제목이 표 위에 있든 아래에 있든 돼요). "Source:", "Note:" 줄은 그대로 번역해요.
- **원문 대조**: 번역 문장과 원문 문장을 서로 회색으로 표시해요. 스캔 PDF의 OCR 글자 폭도 보정해요.
- **형광펜·밑줄**: 조테로와 같은 8색. 번역문 일부에 칠하면 원문의 같은 부분에도 조테로 주석이 생기고, 원문에서 칠하거나 지우면 번역문도 따라와요.
- **각주**: 각주 번호는 위첨자로 보여 주고, 누르면 각주 내용을 번역해서 보여 줘요. 주석 문단은 따로 표시해요.
- **서지 정보**: 맨 앞에 "Park·Abelmann(2004)의 「제목」" 형식으로 보여 줘요.
- **미리 번역**: 지금 쪽과 다음 두 쪽 자동 번역, 전체 또는 쪽 범위 번역. 번역 결과는 저장해서 다시 쓰고 토큰을 아껴요.
- **스캔한 책**: 옆으로 눕혀 스캔한 쪽(90·180·270도), 한 장에 펼친 두 쪽, 기울어진 스캔도 바로 세워 읽어요.
- **깨진 대문자**: 글꼴 문제로 대문자가 소문자로 들어간 PDF(예: "however", "heath 2003")도 문장을 제대로 나눠요.
- **읽기**: 번역은 오른쪽 칸에 끝까지 쭉 보여요. 번역 끝에서 조금 더 내리면 다음 쪽으로 넘어가고, 새 번역의 맨 위가 보여요. 오른쪽 아래에 "‹ 이전 쪽", "다음 쪽 ›" 단추가 늘 떠 있어요.

## 설치

1. [Releases](https://github.com/2yubin/trans_yb/releases/latest)에서 `trans_yb.xpi`를 받아요.
2. 조테로에서 Tools → Plugins → 톱니바퀴 → Install Plugin From File로 설치해요.
3. 조테로를 껐다 켜요.

설치한 뒤에는 새 버전이 나오면 조테로가 알아서 업데이트해요(Tools → Plugins → 톱니바퀴 → Check for Updates로 바로 확인할 수도 있어요).

조테로 10 이상에서 설치돼요. 조테로 10, 맥에서만 시험했어요. 새 조테로에서 플러그인이 켜지지 않으면 안내 창이 한 번 뜨고, 조테로는 그대로 쓸 수 있어요. Claude Code나 Codex 엔진을 쓰려면 그 프로그램이 설치되고 로그인돼 있어야 해요.

## 사용법

### 1. 처음 한 번: 번역 엔진 고르기

1. 조테로에서 PDF를 열어요.
2. 오른쪽 사이드바 옆 아이콘 줄에서 trans_yb 아이콘을 눌러 "trans_yb" 칸을 열어요.
3. **번역 엔진 설정**을 펼쳐 엔진 하나를 골라요.

| 엔진 | 필요한 것 | 비고 |
|---|---|---|
| Claude Code (기본) | 컴퓨터에 Claude Code 설치, 로그인 | API 키가 필요 없어요. 로그인한 계정 사용량을 써요. |
| Codex | 컴퓨터에 Codex 설치, 로그인 | API 키가 필요 없어요. 로그인한 계정 사용량을 써요. |
| Claude API | Anthropic API 키 | 엔진을 고르면 키 입력 칸이 나와요. `sk-ant-…` 키를 넣고 **저장**을 눌러요. 사용한 만큼 요금이 나가요. |
| Google | 없음 | 무료예요. |

Claude Code와 Codex는 플러그인이 설치 위치를 알아서 찾아요(`~/.local/bin`, `/opt/homebrew/bin`, `/usr/local/bin`).

### 2. 한 쪽 번역하기

1. 맨 위 **이 페이지 번역** 단추 옆에서 번역할 언어를 골라요(기본: 한국어).
2. **이 페이지 번역**을 눌러요. 지금 보는 쪽이 문단 단위로 번역돼 아래에 나와요.
3. 번역 맨 위에는 서지 정보, 쪽 번호, 문단 수, 문장 수가 보여요.

**미리 번역 설정**의 **자동 번역**을 켜 두면 쪽을 넘길 때마다 지금 쪽과 다음 두 쪽을 미리 번역해 둬요.

### 3. 원문과 맞춰 읽기

- **번역 문장에 커서를 대면** PDF에서 같은 원문 문장이 칠해져요.
- **PDF 원문 문장에 커서를 대면** 사이드바의 번역 문장이 칠해져요.
- **번역 문장을 두 번 누르면** PDF가 그 원문 문장이 있는 쪽으로 가서 가운데에 보여 줘요.
- **위첨자 각주 번호를 누르면** 각주 창이 떠서 그 각주를 번역해 보여 줘요. **닫기**로 닫아요.
- 앞 쪽에서 이어진 문장은 첫 문단 안에 보통 글씨로 붙어 나와요.

### 4. 쪽 넘기기

- 번역 끝에서 조금 더 내리면 다음 쪽으로 넘어가요.
- 오른쪽 아래 **‹ 이전 쪽**, **다음 쪽 ›** 단추로도 넘길 수 있어요.

### 5. 형광펜과 밑줄

1. 번역문에서 칠하고 싶은 부분을 드래그해요.
2. 작은 막대가 뜨면 **형광펜** 또는 **밑줄**을 고르고, 8가지 색 중 하나를 눌러요.
3. PDF 원문의 같은 부분에도 조테로 주석이 생겨요.
4. 지우려면 같은 부분을 드래그한 뒤 **지우기**를 눌러요.

PDF 원문에서 조테로로 칠하거나 지워도 번역문이 따라 바뀌어요.

### 6. 여러 쪽을 한꺼번에 번역하기

**미리 번역 설정**을 펼쳐요.

- **전체 페이지 → 모두 번역**: 논문 전체를 번역해요.
- **쪽 범위**: 시작 쪽과 끝 쪽을 넣고 **번역**을 눌러요. 끝 쪽을 비우면 마지막 쪽까지 번역해요.
- 진행 막대에 "n/m쪽 번역함"이 보여요. **중지**를 누르면 멈춰요.

한 번 번역한 쪽은 저장해 두기 때문에 다시 열어도 바로 나오고 토큰을 다시 쓰지 않아요.

### 7. 글씨 바꾸기

**글씨 설정**을 펼치면 번역 글씨 **크기**와 **색상**을 바꿀 수 있어요. 색 코드(예: `#6b4423`)를 넣고 Enter를 눌러도 돼요. **기본 색으로**를 누르면 원래 색으로 돌아가요.

### 이럴 때는

| 보이는 문구 | 뜻과 할 일 |
|---|---|
| PDF 화면에서만 쓸 수 있어요. | PDF를 연 화면에서 써 주세요. |
| n쪽에는 글자 정보가 없어요. 스캔한 PDF일 수 있어요. | 그 쪽에 PDF 글자 정보가 없어요. 글자 인식(OCR)을 하지 않은 스캔 PDF일 수 있어요. |
| 번역하지 못했어요. 다시 눌러 주세요. | 엔진 연결이 실패했어요. 다시 눌러 보고, 계속되면 엔진의 로그인 상태나 API 키를 확인해 주세요. |
| 이 각주 내용을 PDF에서 찾지 못했어요. | 각주 부분의 글자 인식이 깨졌을 수 있어요. |

## 폴더 구조

| 파일 | 하는 일 |
|---|---|
| `addon/manifest.json` | 플러그인 이름, 버전, 지원하는 조테로 버전 |
| `addon/bootstrap.js` | 조테로가 플러그인을 켜고 끌 때 부르는 입구 |
| `addon/prefs.js` | 기본 설정 |
| `addon/content/trans_yb.js` | 실제 기능. 위쪽은 문단·문장 계산, 아래쪽은 조테로 화면 연결 |
| `addon/locale/` | 사이드바 제목 문구 |
| `test/` | 문장 나누기, 문단 알아보기, 각주 찾기 시험 |
| `build.sh` | 시험을 돌리고 `build/trans_yb.xpi`를 만들어요 |

## 고친 뒤 다시 만들기

```sh
sh build.sh     # 시험을 돌리고 설치 파일을 만들어요
sh release.sh   # (저장소 주인) manifest.json 버전을 올린 뒤 실행하면 Releases에 올리고 자동 업데이트 정보를 고쳐요
```

## 개인정보

번역할 때 논문 문장이 고른 번역 엔진(Anthropic, OpenAI, Google)의 서버로 보내져요. 번역 결과와 기록은 조테로 데이터 폴더의 `trans_yb` 안에 저장돼요.
